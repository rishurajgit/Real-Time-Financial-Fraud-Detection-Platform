# SentinelRisk — Real-Time Financial Fraud Detection Platform

SentinelRisk is a multi-service financial fraud detection platform built incrementally across Phases 1–6. It combines a **React + TypeScript + Vite** analyst console, an **Express + TypeScript** dashboard backend/proxy, and a dedicated **Python FastAPI + XGBoost** ML training and real-time inference service.

## Service Responsibilities

| Service | Runtime & Port | Responsibility |
| --- | --- | --- |
| **React Dashboard** (`src/`) | Vite / React 19 on `:3000` | Analyst workspace showing real FastAPI XGBoost readiness, live predictions, loading/error/503 states, and clearly separated historical simulated streams. |
| **Express Server** (`server.ts`, `src/server/mlProxy.ts`) | Node.js / Express on `:3000` | Serves frontend, validates and proxies `/api/v1/ml/*` to FastAPI with timeout/error handling, preserves existing SSE and simulator routes. |
| **FastAPI ML Service** (`ml_service/src/api/`) | Python / Uvicorn on `:8000` | Loads trained Phase 1 XGBoost bundle, aligns features without training-serving skew, executes `predict_proba()`, tracks latency/metrics, serves `/docs`. |
| **Phase 1 ML Pipeline** (`ml_service/src/{data,eda,features,models}/`) | Python CLI | Loads & merges IEEE-CIS CSVs, runs EDA + charts, engineers causal behavioral features, trains class-weighted/SMOTE XGBoost, saves artifacts. |

## Model Artifact Requirements & Leakage Prevention

FastAPI loads trained Phase 1 artifacts from `SENTINEL_MODEL_OUTPUT_DIR` (default: `ml_service/artifacts/models/xgboost/`):

- `model_bundle.joblib` *(required)* — contains trained `XGBClassifier`, fitted `FraudFeaturePreprocessor`, exact `feature_names`, `model_version`, and validation-calibrated `review_threshold` / `block_threshold`.
- `metrics.json` *(optional, generated by Phase 1)* — measured validation PR-AUC, ROC-AUC, F1, confusion matrix.
- `pr_curve.json` *(optional, generated by Phase 1)* — validation precision-recall coordinates.

### Target-Encoding Leakage Protection
- During training (`FraudFeaturePreprocessor.fit_transform`), Bayesian-smoothed `{category}_risk_rate` features are computed via **deterministic out-of-fold (OOF) K-fold encoding** (label-independent fold assignment, default 5 folds, seeded by `random_state`). Every training row's encoded risk rate excludes its own fold and own label.
- During validation and live FastAPI inference (`FraudFeaturePreprocessor.transform`), mappings fitted exclusively on the training split are applied (with unseen categories falling back to the training global fraud rate), preserving exact feature ordering.

### Node / Vite Compatibility
- Root `package.json` pins `esbuild` to `^0.28.2` for full compatibility with `vite ^8.3.0`.

If `model_bundle.joblib` is missing, FastAPI starts in **degraded (`model_ready: false`)** mode and returns **HTTP 503 (`model_not_ready`)** on `/predict` and `/predict/batch`. It never fabricates predictions or falls back to a dummy model.

Download the official Kaggle IEEE-CIS dataset (`train_transaction.csv`, `train_identity.csv`, `test_transaction.csv`, `test_identity.csv`) into `ml_service/data/raw/` — see `ml_service/data/README.md`.

## Environment Variables

### Root `.env` (Express + Vite — see `.env.example`)
- `APP_URL` — Application base URL (default `http://localhost:3000`).
- `ML_SERVICE_URL` — FastAPI base URL (default `http://127.0.0.1:8000`).
- `ML_SERVICE_TIMEOUT_MS` — Express proxy request timeout in ms (default `5000`).

### `ml_service/.env` (Python ML Service — see `ml_service/.env.example`)
- `SENTINEL_DATA_DIR` — Raw IEEE-CIS CSV directory (`./data/raw`).
- `SENTINEL_EDA_OUTPUT_DIR` — EDA output directory (`./artifacts/eda`).
- `SENTINEL_MODEL_OUTPUT_DIR` — Trained XGBoost artifact directory (`./artifacts/models/xgboost`).
- `SENTINEL_REVIEW_THRESHOLD` / `SENTINEL_BLOCK_THRESHOLD` — Optional decision threshold overrides (defaults to Phase 1 calibrated bundle thresholds).

## API Endpoint Documentation

### FastAPI ML Service (`http://127.0.0.1:8000`) — Swagger UI at `/docs`
| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/health` | Service status (`ok` / `degraded`), `model_ready`, `model_version`, `missing_artifacts`, uptime. |
| `GET` | `/model/info` | Loaded artifact details, feature count/names, thresholds, measured validation metrics, PR curve. |
| `POST` | `/predict` | Single transaction XGBoost inference (`200` on success, `422` invalid schema, `503` model not ready). |
| `POST` | `/predict/batch` | Batch inference for 1–500 transactions (`200`, `422`, `503`). |
| `GET` | `/metrics` | Runtime prediction counts, decision distribution, avg/p95/p99 latency, error counts. |
| `POST` | `/model/reload` | Atomically reloads `model_bundle.joblib` from disk without restarting FastAPI. |
| `GET` | `/features/{transaction_id}` | Returns engineered and model-input feature vectors cached for a scored transaction (`404` if unknown). |

### Express Proxy Routes (`http://localhost:3000`)
| Method | Path | Upstream FastAPI Target |
| --- | --- | --- |
| `GET` | `/api/v1/ml/health` | `GET /health` |
| `GET` | `/api/v1/ml/model/info` | `GET /model/info` |
| `GET` | `/api/v1/ml/metrics` | `GET /metrics` |
| `POST` | `/api/v1/ml/predict` | `POST /predict` (validates payload -> `400`, timeout -> `504`, offline -> `503`) |
| `POST` | `/api/v1/ml/predict/batch` | `POST /predict/batch` |
| `POST` | `/api/v1/ml/model/reload` | `POST /model/reload` |
| `GET` | `/api/v1/ml/features/:transactionId` | `GET /features/{transaction_id}` |
| `GET` | `/api/v1/ml/predictions` | Recent real XGBoost-scored transactions proxied through Express |

## Windows PowerShell Setup & Local Startup

### 1. Python Virtual Environment & Dependencies
```powershell
cd ml_service
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements-phase2.txt
```

### 2. Optional: Run Phase 1 EDA & Train Real XGBoost Model (Requires Kaggle IEEE-CIS CSVs in `ml_service\data\raw\`)
```powershell
python -m src.eda.analyze
python -m src.models.train_xgboost
```

### 3. Start FastAPI on Port 8000 (Terminal 1)
```powershell
cd ml_service
.\.venv\Scripts\Activate.ps1
uvicorn src.api.app:app --host 127.0.0.1 --port 8000 --reload
```
Swagger docs: `http://127.0.0.1:8000/docs`

### 4. Start Express + React Dashboard on Port 3000 (Terminal 2)
```powershell
npm install
npm run dev
```
Dashboard: `http://localhost:3000`

### 5. Manual Verification Commands (PowerShell — Terminal 3)
```powershell
# Check FastAPI health & model readiness
Invoke-RestMethod http://127.0.0.1:8000/health
Invoke-RestMethod http://127.0.0.1:8000/model/info

# Send direct FastAPI prediction

  transaction_id  = "TX-WIN-001"
  transaction_dt  = 86400
  transaction_amt = 645.50
  product_cd      = "C"
  card1           = 13926
  card4           = "visa"
  card6           = "credit"
  addr1           = 315
  addr2           = 87
```

## Known Limitations (Phase 2 Scope)

- **GNN Scoring (Phase 4 Pending)**: FastAPI reports `gnn_available: false`, `gnn_probability: null`, and `scoring_mode: "xgboost_only"` until PyTorch Geometric graph training is implemented in Phase 4.

- **MLflow & Evidently AI Live Wiring (Phase 5 Pending)**: `ModelMlflowView` displays live FastAPI artifact validation metrics when loaded alongside pre-Phase 5 baseline reference curves.
